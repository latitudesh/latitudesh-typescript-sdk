# RequirementsState

draft while they're being prepared; awaiting_signature to review and sign; signed once an owner or administrator signs. Any later change asks for a new signature.

## Example Usage

```typescript
import { RequirementsState } from "latitudesh-typescript-sdk/models";

let value: RequirementsState = "draft";
```

## Values

```typescript
"draft" | "awaiting_signature" | "signed"
```
